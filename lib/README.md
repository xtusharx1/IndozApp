Indoz TV — Flutter (Android) starter

This folder contains a minimal Flutter app scaffold under `lib/src` with screens and widgets.

How to run

1. Install Flutter and Android toolchain
2. From `android_app/` run:

```bash
flutter pub get
flutter run
```

Notes
- All backend calls are placeholders in `src/services/api_service.dart`.
- UI uses simple placeholders and a consistent theme (gradient background, white cards, orange buttons).
- Customize and extend the code as needed.
